# 📌 Static

## Overview

The **Static** module is the engine orchestration layer of the TKD Engine, managing the lifecycle and coordination of all major engine subsystems. It provides a unified interface for initializing, running, and shutting down the engine's core systems including window management, world simulation, networking, and audio.

Static is designed to be:
- **Subsystem-based**: Each major system runs as an independent subsystem with a common lifecycle
- **Threaded**: Subsystems can run in dedicated threads for parallel execution
- **Interface-driven**: Global static interfaces provide safe access to subsystems from anywhere
- **Client/Server aware**: Conditional compilation supports dedicated server builds without client-only features
- **Game-agnostic**: Supports dynamic game module loading via the TKD_EXPORT_GAME macro

## Architecture

The Static module is organized into **3 architectural layers**:

```
Static/
├── Core/                          - Engine orchestration and subsystem management
│   ├── Engine.hpp/cpp            - Main engine class and game entry point
│   ├── IEngineSubsystem.hpp      - Base interface for all subsystems
│   └── FThreadedSubsystem.hpp/cpp - Base class for threaded subsystems
│
├── Subsystems/                    - Concrete subsystem implementations
│   ├── FWindowSubsystem.hpp/cpp  - Window, rendering, and input (client only)
│   ├── FWorldSubsystem.hpp/cpp   - Game world and simulation loop
│   └── FNetworkSubsystem.hpp/cpp - Server and client networking
│
└── Interfaces/                    - Global static access layer
    ├── FEngineInterface.hpp/cpp   - Engine lifecycle management
    ├── FAudioInterface.hpp/cpp    - Audio system access
    ├── FWindowInterface.hpp/cpp   - Window and input access
    ├── FWorldInterface.hpp/cpp    - World and actor access
    └── FNetworkInterface.hpp/cpp  - Networking operations
```

All Static module classes reside in the `tkd::__internal` namespace, with public-facing interfaces in the `tkd` namespace. Convenience aliases (`Engine`, `Audio`, `Window`, `World`, `Network`) are provided for easier access.

## Engine Orchestration

### IEngineSubsystem

**IEngineSubsystem** - Abstract interface defining the common lifecycle for all engine subsystems.

```cpp
class IEngineSubsystem
{
protected:
    TAtomic<bool> m_initialized{ false };
    TAtomic<bool> m_running{ false };

public:
    virtual ~IEngineSubsystem() = default;

    // Lifecycle methods
    virtual bool Initialize(void) = 0;
    virtual void Start(void);
    virtual void RequestShutdown(void);
    virtual void Shutdown(void);

    // State queries
    TKD_NODISCARD virtual bool IsRunning(void) const noexcept;
    TKD_NODISCARD virtual bool IsInitialized(void) const noexcept;
};
```

**Lifecycle Flow:**
1. **Initialize()** - Allocate resources, create objects, validate configuration (blocking)
2. **Start()** - Begin execution (may spawn threads for threaded subsystems)
3. **Running** - Main execution loop processes game logic, rendering, networking
4. **RequestShutdown()** - Signal graceful shutdown (sets m_running to false)
5. **Shutdown()** - Clean up resources, join threads, finalize state

**Key Characteristics:**
- Thread-safe state management using atomic booleans
- Pure virtual `Initialize()` forces implementation in derived classes
- Default implementations for lifecycle methods can be overridden
- Non-copyable, non-movable to prevent subsystem duplication

### Engine

**Engine** - Central orchestrator managing all engine subsystems, initialization order, main loop, and shutdown sequence.

```cpp
namespace tkd::__internal
{

class Engine
{
private:
    // Subsystems
#if TKD_ENGINE_CLIENT
    TUniquePtr<FWindowSubsystem> m_window;
#endif
    TUniquePtr<FNetworkSubsystem> m_network;
    TUniquePtr<FWorldSubsystem> m_world;
    
    // Game module
    TUniquePtr<AGameMode> m_game;
    TSharedPtr<FLibrary> m_gameLibrary;
    
    // Configuration and state
    FEngineSettings m_settings;
    TAtomic<bool> m_running{ false };
    TAtomic<bool> m_initialized{ false };
    int m_exitCode{ 0 };

public:
    Engine() = default;
    ~Engine() = default;

    // Lifecycle
    bool Initialize(int argc, char* argv[]);
    void Run(void);
    void RequestShutdown(void) noexcept;
    void Shutdown(void);

    // State queries
    TKD_NODISCARD bool IsRunning(void) const noexcept;
    TKD_NODISCARD bool IsInitialized(void) const noexcept;
    TKD_NODISCARD int GetExitCode(void) const noexcept;

    // Subsystem access
    TKD_NODISCARD FWorldSubsystem* GetWorld(void) const noexcept;
    TKD_NODISCARD FNetworkSubsystem* GetNetwork(void) const noexcept;
#if TKD_ENGINE_CLIENT
    TKD_NODISCARD FWindowSubsystem* GetWindow(void) const noexcept;
#endif

    // Game module access
    TKD_NODISCARD AGameMode* GetGame(void) const noexcept;
    TKD_NODISCARD const FEngineSettings& GetSettings(void) const noexcept;

    // Utilities
    void PrintStartupMessage(void) const;
    void PrintExitMessage(void) const;

private:
    void ProcessCommandLine(int argc, char* argv[]);
    void SetupRenderCallback(void);
};

}  // namespace tkd::__internal
```

**Key Methods:**

**Initialize(argc, argv)**
- Loads configuration from `engine.ini`
- Processes command-line arguments (--host, --port, --connect, --debug, --verbose, --game)
- Dynamically loads game module via TKD_EXPORT_GAME
- Initializes subsystems in dependency order: World → Window (client) → Network
- Returns false if any subsystem fails to initialize

**Run()**
- Prints ASCII art startup banner with engine version
- Starts all subsystems (spawns threads for threaded subsystems)
- Main loop monitors:
  - Window close events (client builds)
  - Subsystem running states
  - Shutdown requests
- Shuts down subsystems in reverse order when exiting
- Prints exit message with total runtime

**Command-Line Arguments:**
- `--host <address>` - Set server host address (default: "localhost")
- `--port <port>` - Set server port (default: 8080)
- `--connect` - Auto-connect to server on client startup
- `--debug` - Enable debug logging
- `--verbose` - Enable trace-level logging
- `--game <module>` - Load specific game module (overrides engine.ini)

**Client/Server Differentiation:**
```cpp
#if TKD_ENGINE_CLIENT
    // Client-only code: window, renderer, input
    m_window = std::make_unique<FWindowSubsystem>(m_settings);
    m_window->Initialize();
#endif

#if TKD_ENGINE_SERVER
    // Server-only code: headless operation
#endif
```

### Game Module Loading

**TKD_EXPORT_GAME Macro** - Creates the entry point for dynamically loaded game modules.

```cpp
// Macro definition in Engine.hpp
#define TKD_EXPORT_GAME(GameClass)                                    \
    extern "C" TKD_EXPORT_WEAK tkd::AGameMode* CreateGame(void)       \
    {                                                                  \
        return new GameClass();                                        \
    }

// Usage in game code
class MyGame : public AGameMode
{
    // Game implementation
};

TKD_EXPORT_GAME(MyGame)
```

The engine loads game modules as dynamic libraries (.so/.dll/.dylib) and calls the `CreateGame()` function to instantiate the game mode.

**Usage Example:**

```cpp
// Initialize engine
Engine engine;
if (!engine.Initialize(argc, argv)) {
    return -1;
}

// Run main loop (blocks until shutdown)
engine.Run();

// Cleanup
engine.Shutdown();

return engine.GetExitCode();
```

## Threaded Subsystems

### FThreadedSubsystem

**FThreadedSubsystem** - Base class for subsystems requiring dedicated thread execution with built-in synchronization primitives.

```cpp
class FThreadedSubsystem : public IEngineSubsystem
{
private:
    std::thread m_thread;
    std::mutex m_mutex;
    std::shared_mutex m_dataMutex;
    std::condition_variable m_cv;

protected:
    FThreadedSubsystem() = default;

public:
    virtual ~FThreadedSubsystem();

    // Lifecycle overrides
    void Start(void) override;
    void Shutdown(void) override;

    // Template method - must be implemented by derived classes
    virtual void ThreadLoop(void) = 0;

    // Interruptible wait
    template <typename D>
    void WaitFor(const D& duration)
    {
        if (!m_running.load(std::memory_order_acquire))
            return;

        std::unique_lock lock(m_mutex);
        m_cv.wait_for(lock, duration, 
            [this]() { return !m_running.load(std::memory_order_acquire); });
    }

    // Non-copyable, non-movable
    TKD_DISABLE_COPY_MOVE(FThreadedSubsystem)
};
```

**Threading Model:**
- **Start()** spawns a dedicated `std::thread` that calls `ThreadLoop()`
- **ThreadLoop()** is a pure virtual method implementing the subsystem's main loop
- **WaitFor()** provides interruptible sleep using condition variable
- **Shutdown()** signals thread to stop and joins it

**Synchronization:**
- `m_mutex` - General purpose mutex for thread lifecycle
- `m_dataMutex` - Shared mutex for subsystem-specific data (read-write lock)
- `m_cv` - Condition variable for interruptible waits
- Atomic `m_running` and `m_initialized` flags for state queries

**Memory Ordering:**
- Uses `std::memory_order_acquire` for reads
- Uses `std::memory_order_release` for writes
- Ensures proper synchronization across threads

**Destructor:**
```cpp
FThreadedSubsystem::~FThreadedSubsystem()
{
    if (m_running.load(std::memory_order_acquire))
    {
        RequestShutdown();
    }

    if (m_thread.joinable())
    {
        m_thread.join();
    }
}
```

Ensures threads are always properly cleaned up even if Shutdown() wasn't explicitly called.

### FWindowSubsystem (Client Only)

**FWindowSubsystem** - Manages window creation, rendering, input processing, and VR initialization for client builds.

```cpp
#if TKD_ENGINE_CLIENT

    // Performance metrics

    TAtomic<float> m_averageFrameTime{ 0.0f };

    // Thread safety
    mutable std::shared_mutex m_windowMutex;

public:
    explicit FWindowSubsystem(const FEngineSettings& settings);

    // Lifecycle
    bool Initialize(void) override;
    void Shutdown(void) override;

    // Window properties
    TKD_NODISCARD bool IsOpen(void) const noexcept;
    TKD_NODISCARD FVector2u GetDimensions(void) const;
    void SetTitle(const FString& title);

    // Rendering
    void SetRenderCallback(RenderCallback callback);
    TKD_NODISCARD IRenderer* GetRenderer(void) const noexcept;
    TKD_NODISCARD IGraphicsFactory* GetGraphicsFactory(void) const noexcept;
    TKD_NODISCARD FCamera& GetCamera(void) const noexcept;

    // Input
    TKD_NODISCARD FInputManager* GetInputManager(void) noexcept;

    // Performance
    TKD_NODISCARD float GetFPS(void) const noexcept;
    TKD_NODISCARD float GetAverageFrameTime(void) const noexcept;

    // Internal
    IWindow* GetWindow(void) const noexcept;

protected:
    void ThreadLoop(void) override;
};

#endif  // TKD_ENGINE_CLIENT
```

**Initialization Sequence:**
1. Create SFML graphics factory
2. Set factory in global resource manager (`URessource::GetInstance()`)
3. Create window with settings (title, dimensions, fullscreen)
4. Create renderer attached to window
5. Initialize input manager
6. Deactivate OpenGL context in main thread (will activate in render thread)

**ThreadLoop() Execution:**
```cpp
void FWindowSubsystem::ThreadLoop(void)
{
    // 1. Activate OpenGL context for this thread
    m_window->SetActive(true);

    // 2. Initialize VR if enabled
    if (m_settings.vr.capability != EVRCapability::Disabled) {
        VR::FVRSystem& vrSystem = VR::FVRSystem::GetInstance();
        if (!vrSystem.Initialize() && 
            m_settings.vr.capability == EVRCapability::Required) {
            RequestShutdown();
            return;
        }
    }

    // 3. Main render loop
    while (m_running && m_window->IsOpen())
    {
        // Process events and input
        m_window->Update(deltaTime);
        m_inputManager->Update(m_window.get());

        // Render frame
        m_renderer->BeginFrame();
        m_window->Draw([this]() {
            if (m_renderCallback) {
                m_renderCallback(*m_renderer);
            }
        });
        m_renderer->EndFrame();

        // Update FPS metrics
        // (calculates FPS every second, tracks average frame time)
    }

    // 4. Cleanup
    m_window->Close();
}
```

**Multi-threaded Rendering:**
- OpenGL context is activated in the render thread, not main thread
- Window events and rendering happen in dedicated thread
- Thread-safe access via `std::shared_mutex` for window queries
- Atomic variables for FPS and frame time metrics

**VR Support:**
- Checks `m_settings.vr.capability` (Disabled, Optional, Required)
- Initializes VR system if enabled
- Fails initialization if VR is Required but unavailable

**Performance Tracking:**
- FPS calculated every second from frame count
- Average frame time uses exponential moving average (95% old + 5% new)
- Atomic storage allows thread-safe reads

### FWorldSubsystem

**FWorldSubsystem** - Manages the game world, actor lifecycle, and simulation tick loop.

```cpp
class FWorldSubsystem final : public FThreadedSubsystem
{
private:
    TUniquePtr<UWorld> m_world;
    mutable std::shared_mutex m_worldMutex;
    
    // Tick configuration
    float m_targetTickRate;          // Fixed tick rate (0 = variable)
    float m_fixedDeltaTime;          // 1.0 / targetTickRate
    
    // Metrics
    TAtomic<double> m_simulationTime{ 0.0 };
    TAtomic<float> m_averageTickTime{ 0.0f };

public:
    explicit FWorldSubsystem(float targetTickRate = 120.0f);

    // Lifecycle
    bool Initialize(void) override;

    // World access
    TKD_NODISCARD UWorld* GetWorld(void) const noexcept;

    // Thread-safe world access patterns
    template <typename Func>
    auto WithWorld(Func&& func) -> decltype(func(std::declval<UWorld&>()))
    {
        std::unique_lock lock(m_worldMutex);
        return func(*m_world);
    }

    template <typename Func>
    auto WithWorldReadOnly(Func&& func) const
        -> decltype(func(std::declval<const UWorld&>()))
    {
        std::shared_lock lock(m_worldMutex);
        return func(*m_world);
    }

    // Simulation metrics
    TKD_NODISCARD double GetSimulationTime(void) const noexcept;
    TKD_NODISCARD float GetAverageTickTime(void) const noexcept;
    void SetTargetTickRate(float tickRate) noexcept;

    // World queries
    const AGameMode& GetGameMode(void) const;
    const std::vector<ULevel>& GetLoadedLevels(void) const;
    ULevel* GetCurrentLevel(void) const;

protected:
    void ThreadLoop(void) override;
};
```

**Initialization:**
- Creates `UWorld` instance
- Marks subsystem as initialized
- World initialization deferred to ThreadLoop's BeginPlay

**ThreadLoop() Execution:**

**Fixed Timestep Mode** (m_fixedDeltaTime > 0):
```cpp
void FWorldSubsystem::ThreadLoop(void)
{
    // 1. Begin Play
    m_world->BeginPlay();

    float accumulator = 0.0f;

    // 2. Main loop
    while (m_running)
    {
        float frameTime = /* measure real time elapsed */;
        frameTime = Math<float>::Min(frameTime, 0.25f);  // Prevent spiral of death
        accumulator += frameTime;

        // 3. Fixed timestep updates
        while (accumulator >= m_fixedDeltaTime)
        {
            // Process deferred RPCs BEFORE acquiring world lock
            Network::ProcessDeferredRPCs(*m_world);
            Network::ProcessDeferredPropertyReplications(*m_world);

            // Tick world with fixed delta time
            {
                std::unique_lock lock(m_worldMutex);
                m_world->Tick(m_fixedDeltaTime);
                m_world->ProcessDeferredSpawns();
            }

            m_simulationTime += m_fixedDeltaTime;
            accumulator -= m_fixedDeltaTime;
        }

        // 4. Sleep to maintain target tick rate
        WaitFor(targetFrameDuration);
    }

    // 5. End Play
    m_world->EndPlay();
}
```

**Variable Timestep Mode** (m_fixedDeltaTime == 0):
```cpp
// Similar structure but ticks with actual frame time
m_world->Tick(frameTime);
// Small sleep to prevent 100% CPU usage
WaitFor(Milliseconds(1));
```

**Tick Rate Options:**
- **120 Hz (default)** - Good balance for fast-paced games
- **60 Hz** - Standard for most games
- **30 Hz** - Low tick rate for slow-paced games
- **Variable** - Tick with actual frame time (not recommended for physics)

**Accumulator Pattern:**
Prevents "spiral of death" where slow frames cause more work, causing slower frames:
- Clamp frame time to 0.25s maximum
- Accumulate time and tick in fixed increments
- Ensures deterministic simulation regardless of frame rate

**Deferred Processing:**
- RPCs processed **before** acquiring world mutex to prevent deadlocks
- Deferred spawns processed **after** tick while holding lock
- Property replications processed before tick

**Thread Safety:**
- `std::unique_lock` for exclusive write access (Tick, spawn)
- `std::shared_lock` for concurrent read access (queries)
- Deferred spawn queue allows spawning from Tick() without deadlock

### FNetworkSubsystem


**Initialization:**
- **Server Mode**: Creates `FNetworkServer` and starts listening on port
- **Client Mode**: Creates `FNetworkClient` (connection deferred until settings are set)
- **Disabled Mode**: No-op, returns success immediately

**Engine Settings Validation:**
```cpp
void FNetworkSubsystem::SetEngineSettings(const FEngineSettings& settings)
{
    if (m_server) {
        m_server->SetEngineSettings(settings);
    }
    
    if (m_client) {
        m_client->SetEngineSettings(settings);
        
        // Auto-connect after settings are validated
        if (m_config.autoConnect) {
            m_client->Connect(m_config.host, m_config.port);
        }
    }
}
```

Engine settings contain game title and version used for connection validation.

**ThreadLoop() Execution:**
```cpp
void FNetworkSubsystem::ThreadLoop(void)
{
    while (m_running)
    {
        float deltaTime = /* measure frame time */;

        // Update server or client
        if (m_config.mode == Mode::Server && m_server) {
            m_server->Update(deltaTime);
        }
        else if (m_config.mode == Mode::Client && m_client) {
            m_client->Update(deltaTime);
        }

        // Update statistics every second
        // (calculates bytes/sec from accumulated totals)

        // Network tick rate: ~30 Hz
        WaitFor(Milliseconds(33));
    }

    // Cleanup: flush packets before stopping
    if (m_server) {
        m_server->Cleanup();
        m_server->Stop();
    }
    if (m_client) {
        m_client->Disconnect();
    }
}
```

**Deferred RPC Processing:**
```cpp
void FNetworkSubsystem::ProcessDeferredRPCs(UWorld& world)
{
    // NO LOCK on m_networkMutex!
    // Server/client pointers are stable after initialization
    // ProcessDeferredRPCs has its own internal locking (m_rpcQueueMutex)
    // Locking here would cause deadlock with network thread

    if (m_server) {
        m_server->ProcessDeferredRPCs(world);
    }
    else if (m_client) {
        m_client->ProcessDeferredRPCs(world);
    }
}
```

**Deadlock Prevention:**
- World thread calls `ProcessDeferredRPCs()` while holding world mutex
- Network thread processes packets and queues RPCs
- RPC queue has its own mutex (`m_rpcQueueMutex`)
- Not locking `m_networkMutex` in `ProcessDeferredRPCs()` prevents circular wait

**Network Flow:**
1. Network thread receives packet
2. Packet handler queues RPC in deferred queue (locks `m_rpcQueueMutex`)
3. World thread calls `ProcessDeferredRPCs()` (no `m_networkMutex` lock)
4. Deferred queue is swapped and processed (locks `m_rpcQueueMutex` briefly)
5. RPCs execute with world mutex held by caller

### FWorldInterface

**FWorldInterface** - Static interface for world and actor access.

```cpp
class FWorldInterface final
{
private:
    static std::mutex s_mutex;
    static __internal::FWorldSubsystem* GetWorldSubsystem(void);

public:
    // Actor spawning
    template <typename T = AActor>
    static T* SpawnActor(const FTransform& transform = FTransform())
    {
        static_assert(std::is_base_of<AActor, T>::value, 
                     "T must be derived from AActor");

        auto* worldSubsystem = GetWorldSubsystem();
        if (!worldSubsystem) return nullptr;

        T* result = nullptr;
        worldSubsystem->WithWorld([&](UWorld& world) {
            result = world.SpawnActor<T>(transform);
        });

        return result;
    }

    // Deferred spawning (safe to call from Tick)
    template <typename T = AActor>
    static void SpawnActorDeferred(const FTransform& transform = FTransform());

    static void SpawnActorDeferred(const FString& className, 
                                   const FTransform& transform = FTransform());

    // Actor queries
    static std::vector<std::shared_ptr<AActor>> GetActors(void);

    template <typename T>
    static std::vector<T*> GetActorsOfClass(void);

    static std::vector<AActor*> GetActorsByClass(UClass* actorClass, 
                                                 bool includeChildren = true);

    // Actor destruction
    static void DestroyActor(AActor* actor);

    // Time and metrics
    TKD_NODISCARD static float GetTime(void);
    TKD_NODISCARD static double GetSimulationTime(void);
    TKD_NODISCARD static float GetAverageTickTime(void);
    static void SetTargetTickRate(float tickRate);

    // World access
    template <typename Func>
    static auto WithWorld(Func&& func) 
        -> decltype(func(std::declval<UWorld&>()));

    // Level queries
    const AGameMode& GetGameMode(void) const;
    const std::vector<ULevel>& GetLoadedLevels(void) const;
    ULevel* GetCurrentLevel(void) const;
};

using World = tkd::FWorldInterface;
```

**Usage:**

```cpp
// Spawn actor
FTransform spawnTransform;
spawnTransform.SetPosition(FVector3(0, 10, 0));

AEnemy* enemy = World::SpawnActor<AEnemy>(spawnTransform);
if (enemy) {
    enemy->SetHealth(100.0f);
}

// Spawn from class name
World::SpawnActorDeferred("AProjectile", spawnTransform);

// Deferred spawning (safe from Tick)
void APlayer::Tick(float deltaTime)
{
    if (firePressed) {
        FTransform bulletTransform = GetTransform();
        World::SpawnActorDeferred<ABullet>(bulletTransform);
    }
}

// Query actors
auto enemies = World::GetActorsOfClass<AEnemy>();
for (AEnemy* enemy : enemies) {
    enemy->TakeDamage(10.0f);
}

// Get all actors
auto allActors = World::GetActors();
FLogger::Info("Total actors: {}", allActors.size());

// Destroy actor
World::DestroyActor(enemy);

// Time queries
float time = World::GetTime();
double simTime = World::GetSimulationTime();
float tickTime = World::GetAverageTickTime();
FLogger::Debug("World time: {:.2f}s, Tick: {:.2f}ms", time, tickTime);

// Set tick rate
World::SetTargetTickRate(60.0f);  // 60 Hz simulation

// Direct world access
World::WithWorld([](UWorld& world) {
    // Custom world operations
    world.LoadLevel("Level2");
});
```

**Deadlock Warning:**
- `SpawnActor<T>()` acquires world mutex - **do not call from Tick()**
- `SpawnActorDeferred<T>()` queues spawn - **safe to call from Tick()**
- `DestroyActor()` just marks for deletion - **safe to call from Tick()**

## Subsystem Initialization Order

The Engine class initializes subsystems in dependency order to ensure proper setup:

```cpp
bool Engine::Initialize(int argc, char* argv[])
{
    // 1. Load configuration
    LoadEngineSettings("engine.ini");

    // 2. Process command line
    ProcessCommandLine(argc, argv);

    // 3. Initialize World (no dependencies)
    m_world = std::make_unique<FWorldSubsystem>(m_settings.world.tickRate);
    if (!m_world->Initialize()) {
        return false;
    }

#if TKD_ENGINE_CLIENT
    // 4. Initialize Window (depends on World for rendering)
    m_window = std::make_unique<FWindowSubsystem>(m_settings);
    if (!m_window->Initialize()) {
        return false;
    }

    // 5. Setup render callback (connects Window to World)
    SetupRenderCallback();
#endif

    // 6. Initialize Network (may need World for RPCs)
    FNetworkSubsystem::Config netConfig;
    netConfig.mode = /* server/client/disabled */;
    netConfig.port = m_settings.network.port;
    m_network = std::make_unique<FNetworkSubsystem>(netConfig);
    if (!m_network->Initialize()) {
        return false;
    }

    // 7. Set engine settings for validation
    m_network->SetEngineSettings(m_settings);

    // 8. Load game module
    m_gameLibrary = FLibrary::Load(gameDllPath);
    auto createGame = m_gameLibrary->GetFunction<AGameMode*()>("CreateGame");
    m_game = TUniquePtr<AGameMode>(createGame());

    m_initialized = true;
    return true;
}
```

**Dependencies:**
- **World**: No dependencies (base system)
- **Window**: Depends on World for rendering game state
- **Network**: Depends on World for RPC processing
- **Game Module**: Depends on all subsystems being initialized

**Shutdown Order:**
Subsystems are shut down in **reverse order** to ensure proper cleanup:

```cpp
void Engine::Shutdown(void)
{
    // 1. Game module (may reference subsystems)
    m_game.reset();

    // 2. Network (stops sending/receiving)
    if (m_network) {
        m_network->RequestShutdown();
        m_network->Shutdown();
    }

#if TKD_ENGINE_CLIENT
    // 3. Window (stops rendering)
    if (m_window) {
        m_window->RequestShutdown();
        m_window->Shutdown();
    }
#endif

    // 4. World (stops simulation)
    if (m_world) {
        m_world->RequestShutdown();
        m_world->Shutdown();
    }

    m_initialized = false;
}
```

### 2. Deferred Spawning from Tick

```cpp

// GOOD: Check before accessing client-only features
```

## Thread Safety

### Thread-Safe Components

- **All Static Interfaces**: Protected by internal mutexes
- **FThreadedSubsystem**: Atomic state flags with proper memory ordering
- **FWindowSubsystem**: `std::shared_mutex` for window access
- **FWorldSubsystem**: `std::shared_mutex` for world access with read-write locking
- **FNetworkSubsystem**: `std::shared_mutex` for network operations

### Threading Model

**Main Thread:**
- Engine initialization and shutdown
- Static interface calls
- Engine main loop monitoring

**Window Thread (client only):**
- OpenGL context activation
- Event processing
- Rendering
- Input handling

**World Thread:**
- World tick
- Actor lifecycle (BeginPlay, Tick, EndPlay)
- Deferred spawn processing
- Deferred RPC execution

**Network Thread:**
- Socket operations
- Packet sending/receiving
- RPC queueing
- Statistics tracking

### Synchronization Patterns

**Read-Write Lock:**
```cpp
// Multiple readers allowed
world->WithWorldReadOnly([](const UWorld& world) {
    // Concurrent read access
    const auto& actors = world.GetActors();
});

// Exclusive writer
world->WithWorld([](UWorld& world) {
    // Exclusive write access
    world.SpawnActor<AActor>();
});
```

**Lock-Free Deferred Processing:**
```cpp
// Avoid deadlock by processing RPCs BEFORE acquiring world lock
Network::ProcessDeferredRPCs(*m_world);  // No locks

{
    std::unique_lock lock(m_worldMutex);  // Now acquire world lock
    m_world->Tick(deltaTime);
    m_world->ProcessDeferredSpawns();
}
```

**Atomic Metrics:**
```cpp
// Thread-safe performance metrics
TAtomic<float> m_currentFPS{ 0.0f };
TAtomic<double> m_simulationTime{ 0.0 };

// Safe to read from any thread
float fps = m_currentFPS.load(std::memory_order_acquire);
```

## Performance Considerations

### 1. Subsystem Overhead

Each threaded subsystem has:
- One dedicated `std::thread`
- Multiple mutexes (`std::mutex`, `std::shared_mutex`)
- One condition variable
- Atomic state variables

**Impact:** Minimal overhead for 3-4 subsystems, but avoid creating many subsystems unnecessarily.

### 2. Lock Contention

**FWorldSubsystem:**
- World mutex held during entire Tick()
- Deferred spawns minimize lock time
- Read-only operations use shared lock (multiple concurrent readers)

**FWindowSubsystem:**
- Window mutex held during rendering
- Input queries use shared lock
- Minimal contention as rendering is single-threaded

**FNetworkSubsystem:**
- Network mutex only held during Update()
- Deferred RPC processing avoids deadlocks
- ~30 Hz tick rate reduces contention

### 3. Fixed vs Variable Timestep

**Fixed Timestep (recommended):**
- Deterministic simulation
- Network-friendly (consistent tick rate)
- Accumulator prevents spiral of death
- ~5-10% higher CPU usage

**Variable Timestep:**
- Lower CPU usage
- Non-deterministic (frame rate affects gameplay)
- Difficult to network properly

```cpp
// Fixed: 120 Hz (default)
FWorldSubsystem world(120.0f);

// Variable: 0 = uncapped
FWorldSubsystem world(0.0f);
```

### 4. Network Tick Rate

Network subsystem ticks at ~30 Hz (33ms sleep) regardless of world tick rate:
- Reduces bandwidth usage
- Sufficient for most multiplayer games
- Reliable packets add latency but guarantee delivery

### 5. Deferred Operations

**Deferred Spawning:**
- Avoids deadlocks
- Minimal overhead (queues spawn request)
- Processed once per tick after world update

**Deferred RPCs:**
- Queue swapping is lock-free
- RPC execution happens in world thread context
- No network mutex held during execution

### 6. Static Interface Overhead

Each static interface call:
- Acquires mutex (`std::lock_guard`)
- Retrieves subsystem pointer
- Delegates to subsystem

**Impact:** ~10-20 nanoseconds per call. Negligible for game logic, but avoid in tight loops.

```cpp
// GOOD: Cache pointer
FInputManager* input = Window::GetInputManager();
for (int i = 0; i < 1000; ++i) {
    if (input->IsKeyPressed(EInputs::W)) { /* ... */ }
}

// AVOID: Repeated static calls
for (int i = 0; i < 1000; ++i) {
    if (Window::GetInputManager()->IsKeyPressed(EInputs::W)) { /* ... */ }
}
```
