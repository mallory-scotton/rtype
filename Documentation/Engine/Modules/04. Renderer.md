# 🎨 Renderer

## Architecture Overview

The TKD Engine's renderer is a **hybrid 2D/3D rendering system** built on OpenGL with SFML as the windowing backend. It provides a flexible, multi-threaded rendering architecture supporting both traditional 2D sprites and full 3D primitives with optional VR support.

### Core Components

The renderer consists of seven primary layers that work together:

#### 1. **IRenderer** (Abstract Interface)

**Purpose**: Core rendering interface defining all rendering operations, both 2D and 3D.

**Key Features**:
- **Draw Methods**: Multiple overloads for vertices, primitives, and drawable objects
- **View Management**: 2D view control for camera/viewport manipulation
- **Camera Management**: 3D camera support with perspective projection
- **Frame Control**: `BeginFrame()` / `EndFrame()` for proper render lifecycle
- **OpenGL State Management**: Direct control over depth, blending, culling, lighting, etc.
- **Matrix Operations**: Push/pop matrix stack, transformations (translate, rotate, scale)
- **Render Targets**: Switch between window, textures, or VR framebuffers

**Role**: Provides a unified interface for all rendering, allowing multiple backends (currently SFML/OpenGL).

---

#### 2. **SFML::Renderer** (Concrete Implementation)

**Purpose**: SFML-backed OpenGL renderer implementation.

**Dependencies**:
- **SFML Graphics**: `sf::RenderWindow`, `sf::RenderTarget` for windowing and 2D rendering
- **OpenGL**: Direct OpenGL calls (`glBegin`, `glVertex3f`, `glMatrixMode`, etc.) for 3D rendering
- **GLU**: `gluLookAt`, `gluPerspective` for camera and projection setup

**Key Members**:
```cpp
sf::RenderWindow* m_window;              // SFML window
sf::RenderTarget* m_currentTarget;       // Current render target
FView m_currentView;                     // 2D view
FCamera m_camera;                        // 3D camera
std::stack<FRectangle> m_scissorStack;   // Scissor test stack
```

**Hybrid Rendering Approach**:
- **2D Rendering**: Uses SFML's vertex arrays and render states, automatically switches to 2D orthographic projection
- **3D Rendering**: Direct OpenGL immediate mode rendering with GLU perspective projection
- **State Management**: Pushes/pops OpenGL states to safely switch between 2D and 3D modes

**Role**: Implements all `IRenderer` methods, managing the hybrid 2D/3D rendering pipeline.

---

#### 3. **IDrawable** (Interface)

**Purpose**: Abstract interface for any object that can be drawn.

**Key Method**:
```cpp
virtual void Draw(IRenderer& target, FRenderStates states) const = 0;
```

**Implementations**:
- `USprite`: 2D textured sprites
- `UShape`: 2D geometric shapes (rectangles, circles, polygons, etc.)
- `UPrimitive`: 3D geometric primitives (cubes, spheres, cylinders, etc.)

**Role**: Enables polymorphic rendering - any `IDrawable` can be passed to `renderer.Draw()`.

---

#### 4. **FRenderStates**

**Purpose**: Encapsulates rendering state for 2D drawing operations.

**Key Members**:
```cpp
EBlendMode blendMode;          // Alpha, Add, Multiply, None
FTransform2D transform;        // 2D transformation matrix
const ITexture* texture;       // Optional texture
const IShader* shader;         // Optional shader
```

**Role**: Bundles 2D rendering state to avoid parameter proliferation in draw calls.

---

#### 5. **FCamera** (3D Camera)

**Purpose**: Manages 3D camera position, orientation, and projection parameters.

**Key Members**:
```cpp
FVector3 position;          // Camera position in world space
FVector3 front;             // Forward direction vector
FVector3 up;                // Up direction vector
FVector3 right;             // Right direction vector
Float32 yaw;                // Yaw angle (degrees)
Float32 pitch;              // Pitch angle (degrees)
Float32 fov;                // Field of view (degrees)
Float32 aspectRatio;        // Aspect ratio
Float32 nearPlane;          // Near clipping plane
Float32 farPlane;           // Far clipping plane
```

**Usage Pattern**:
```cpp
FCamera camera;
camera.position = FVector3(0, 0, 5);
camera.UpdateCameraVectors();  // Recalculate direction vectors
renderer.SetCamera(camera);     // Apply to renderer
```

**Role**: Provides first-person camera controls for 3D rendering with perspective projection.

---

#### 6. **FView** (2D View/Camera)

**Purpose**: Manages 2D viewport and camera for orthographic 2D rendering.

**Key Members**:
```cpp
FVector2 m_center;          // Center of view in world coordinates
FVector2 m_size;            // Size of view
float m_rotation;           // Rotation angle (degrees)
FRectangle m_viewport;      // Viewport rectangle (normalized 0-1)
```

**Key Methods**:
- `SetCenter()` / `SetSize()`: Define view area
- `Move()` / `Rotate()` / `Zoom()`: Transform view
- `Reset()`: Reset to default

**Role**: Enables 2D camera systems, split-screen rendering, and minimap functionality.

---

#### 7. **IGraphicsFactory** (Factory Pattern)

**Purpose**: Abstract factory for creating all rendering resources.

**Key Creation Methods**:
- `CreateWindow()`: Window with configurable state (fullscreen, windowed, etc.)
- `CreateRenderer()`: Renderer attached to a window
- `CreateTexture()`: Textures from file, memory, or assets
- `CreateShader()`: Shaders from file, memory, or assets
- `CreateRenderTarget()`: Off-screen render targets

**Concrete Implementation**: `SFML::GraphicsFactory`

**Role**: Decouples resource creation from usage, enabling multiple rendering backends.

## Drawable Types

### 2D Drawables

#### **USprite**

**Purpose**: Textured 2D sprite rendering.

**Inherits**: `FTransformable2D`, `IDrawable`

**Key Features**:
- Texture mapping with customizable texture rectangles
- Color modulation (tint)
- Standard 2D transformations (position, rotation, scale, origin)
- Local and global bounds calculation

**Vertex Structure**: 4 vertices (quad) with position, color, and UV coordinates

**Usage**:
```cpp
USprite sprite(texture);
sprite.SetPosition(100, 100);
sprite.SetTextureRect(FRectanglei(0, 0, 64, 64));
sprite.SetColor(FColor::Red);  // Tint red
renderer.Draw(sprite);
```

---

#### **UShape** (Abstract Base)

**Purpose**: Base class for 2D geometric shapes with fill and outline.

**Inherits**: `FTransformable2D`, `IDrawable`

**Key Features**:
- Fill color and outline color
- Outline thickness with miter limit control
- Optional texture mapping
- Automatic geometry generation

**Derived Classes**:
- `URectangleShape`: Rectangles
- `UCircleShape`: Circles
- `UEllipseShape`: Ellipses
- `UTriangleShape`: Triangles
- `UPolygonShape`: Custom polygons
- `UConvexShape`: Convex polygons
- `ULineShape`: Lines

**Geometry Generation**: Shapes implement `GetPointCount()` and `GetPoint(index)` to define geometry

---

### 3D Drawables

#### **UPrimitive** (Abstract Base)

**Purpose**: Base class for 3D geometric primitives.

**Inherits**: `FTransformable`, `IDrawable`

**Key Members**:
```cpp
EPrimitiveType m_primitiveType;    // Triangles, Lines, Points, etc.
std::vector<FVertex> m_vertices;   // 3D vertices (position, color, normal, UV)
FColor m_color;                    // Base color
```

**Primitive Types**:
- `Points`: Individual points
- `Lines`: Line segments
- `LineStrip`: Connected lines
- `Triangles`: Individual triangles
- `TriangleStrip`: Efficient triangle meshes
- `TriangleFan`: Fan-shaped triangle arrays
- `Quads`: Quadrilaterals
- `QuadStrip`: Efficient quad meshes

**Derived Classes**:
- `UCubePrimitive`: Cube/box
- `USpherePrimitive`: UV sphere
- `UCylinderPrimitive`: Cylinder
- `UConePrimitive`: Cone
- `UCapsulePrimitive`: Capsule
- `UPlanePrimitive`: Flat plane
- `UPyramidPrimitive`: Pyramid
- `UPrismPrimitive`: Prism
- `UTorusPrimitive`: Torus/donut
- `UBillboardPrimitive`: Camera-facing quad

**Vertex Structure** (`FVertex`):
```cpp
struct FVertex {
    FVector3 position;   // 3D position
    FColor color;        // Vertex color
    FVector2 uv;         // Texture coordinates
};
```

**Normal Calculation**: Renderer automatically calculates face normals for lighting

## Resource Management

### **ITexture**

**Purpose**: GPU texture resource interface.

**Key Features**:
- **Loading**: From file, memory, bytes, or assets
- **Creation**: Empty textures with specified dimensions
- **Updates**: Dynamic pixel updates (full or partial)
- **Filtering**: Smooth (linear) vs nearest neighbor
- **Wrapping**: Repeat vs clamp
- **Mipmaps**: Automatic mipmap generation
- **sRGB**: Color space management

**Texture Coordinates**: Normalized (0-1) or pixel units

**Usage Pattern**:
```cpp
auto texture = graphicsFactory->CreateTexture();
texture->LoadFromFile("path/to/texture.png");
texture->SetSmooth(true);
texture->GenerateMipmaps();
```

---

### **IShader**

**Purpose**: GPU shader program interface (GLSL).

**Shader Types**:
- `Vertex`: Vertex transformation
- `Fragment`: Pixel/fragment shading
- `Geometry`: Geometry generation
- `Compute`: General-purpose GPU computation

**Key Features**:
- **Loading**: From file, memory, bytes, or assets
- **Uniforms**: Set shader parameters (scalars, vectors, matrices, textures)
- **Uniform Arrays**: Array uniforms for batch data
- **Binding**: Activate/deactivate shader

**Uniform Types Supported**:
- Scalars: `float`, `int`, `bool`
- Vectors: `FVector2/3/4` (float, int, bool variants)
- Matrices: `FMatrix3x3`, `FMatrix4x4`
- Colors: `FColor`, `FLinearColor`
- Textures: `ITexture`

**Usage**:
```cpp
auto shader = graphicsFactory->CreateShader(vertexPath, fragmentPath);
shader->Bind();
shader->SetUniform("time", elapsedTime);
shader->SetUniform("viewMatrix", camera.GetViewMatrix());
shader->SetUniform("texture", *myTexture);
// Draw calls here
shader->Unbind();
```

---

### **IWindow**

**Purpose**: Platform window interface with input handling.

**Key Features**:
- **Lifecycle**: Open, close, state management
- **States**: Windowed, fullscreen, maximized, minimized
- **Input**: Keyboard, mouse, gamepad support
- **Events**: Event-driven architecture (opened, closed, resized, focus, etc.)
- **VSync**: Vertical synchronization control
- **OpenGL Context**: Thread-safe context activation

**Events**:
- `Opened`: Window opened
- `Closed`: Window closed
- `StateChanged`: Window state changed
- `Resized`: Window resized
- `LostFocus` / `GainedFocus`: Focus events
- `Moved`: Window position changed

**Usage**:
```cpp
window->On<IWindow::Events::Resized>([](const auto& event) {
    std::cout << "Resized: " << event.newSize.x << "x" << event.newSize.y;
});
```

## VR Support

### **FVRSystem** (Singleton)

**Purpose**: Main interface for VR hardware (OpenVR/SteamVR backend).

**Key Features**:
- **HMD Tracking**: Head-mounted display position and orientation
- **Controller Tracking**: Left and right controller states
- **Input**: Button states, touchpad, joystick, trigger, grip
- **Haptic Feedback**: Vibration pulses
- **Projection Matrices**: Per-eye projection and view matrices
- **Frame Submission**: Submit rendered frames to compositor

**Initialization Flow**:
```cpp
VR::FVRSystem& vr = VR::FVRSystem::GetInstance();
if (vr.Initialize()) {
    // VR is available
    FVRSpecs specs = vr.GetSpecs();
    // specs.eyeWidth, specs.eyeHeight
}
```

**Rendering Loop**:
```cpp
vr.BeginFrame();
for (EEye eye : {EEye::Left, EEye::Right}) {
    FMatrix4x4 projection = vr.GetProjectionMatrix(eye, 0.1f, 1000.0f);
    FMatrix4x4 eyeToHead = vr.GetEyeToHeadTransform(eye);
    // Render scene for this eye
    vr.SubmitFrame(eye, renderTarget);
}
vr.EndFrame();
```

## Subsystem Integration

### **FWindowSubsystem** (Threaded)

**Purpose**: Dedicated rendering thread managing window, renderer, and input.

**Key Members**:
```cpp
std::unique_ptr<IWindow> m_window;               // Window
std::unique_ptr<IRenderer> m_renderer;           // Renderer
std::unique_ptr<IGraphicsFactory> m_graphicsFactory;  // Factory
std::unique_ptr<FInputManager> m_inputManager;   // Input system
RenderCallback m_renderCallback;                 // User render function
```

**Thread Model**:
- **Main Thread**: Engine logic, world ticking
- **Render Thread**: Window events, input polling, rendering
- **Synchronization**: Thread-safe render callback invocation

**Initialization Flow**:
1. Create `SFML::GraphicsFactory`
2. Create window with specified settings
3. Create renderer attached to window
4. Create input manager
5. **Deactivate OpenGL context on main thread** (critical for multi-threading)
6. Spawn render thread
7. **Activate OpenGL context on render thread**
8. Optional: Initialize VR system

**Render Loop** (on render thread):
```cpp
while (running && window->IsOpen()) {
    // Process events and input
    window->Update(deltaTime);
    inputManager->Update(window);
    
    // Render frame
    renderer->BeginFrame();
    window->Draw([&]() {
        if (renderCallback) {
            renderCallback(*renderer);  // User code
        }
    });
    renderer->EndFrame();
    
    // Update FPS metrics
}
```

---

### **Engine::SetupRenderCallback()**

**Purpose**: Connects world rendering to the window subsystem.

**Implementation**:
```cpp
m_window->SetRenderCallback([this](IRenderer& renderer) {
    if (auto* world = m_world->GetWorld()) {
        world->Render(renderer);  // Render all actors
        
        if (m_settings.debug) {
            debug::FDebug::GetInstance().Show(m_settings, world);
        }
    }
});
```

**Execution**: Called from render thread during `window->Draw()`.

## Rendering Pipeline

### 2D Rendering Flow

```
Application
    ↓
Create USprite/UShape
    ↓
Set texture, color, transform
    ↓
renderer.Draw(sprite, states)
    ↓
SFML::Renderer::Draw(FVertex2D*, ...)
    ↓
Save OpenGL state (glPushAttrib)
Switch to 2D orthographic projection
    ↓
Convert to SFML vertices
    ↓
sf::RenderTarget::draw()
    ↓
Restore OpenGL state (glPopAttrib)
    ↓
Reapply 3D camera perspective
```

**Key Points**:
- Automatically switches between 2D and 3D modes
- 2D uses SFML's optimized rendering
- State preservation ensures no interference with 3D rendering

---

### 3D Rendering Flow

```
Application
    ↓
Create UPrimitive (Cube, Sphere, etc.)
    ↓
Set position, rotation, scale, color
    ↓
renderer.Draw(primitive)
    ↓
primitive.Draw(renderer, states)
    ↓
SFML::Renderer::Draw(FVertex*, EPrimitiveType, FTransform)
    ↓
glPushMatrix()
Apply transformation (translate, rotate, scale)
    ↓
glBegin(GL_TRIANGLES/etc.)
For each triangle:
    Calculate face normal
    glNormal3f(...)
    glTexCoord2f(...)
    glVertex3f(...)
glEnd()
    ↓
glPopMatrix()
```

**Key Points**:
- Uses OpenGL immediate mode for simplicity
- Automatic normal calculation for lighting
- Matrix stack for hierarchical transformations

---

### Hybrid Rendering Example

```cpp
// 3D scene rendering
renderer.BeginFrame();
renderer.Clear(FColor::CornflowerBlue);

// Setup 3D camera
FCamera camera;
camera.position = FVector3(0, 5, 10);
camera.front = FVector3(0, -0.5, -1).Normalized();
camera.UpdateCameraVectors();
renderer.SetCamera(camera);

// Enable 3D features
renderer.SetDepthTest(true);
renderer.SetLighting(true);

// Draw 3D primitives
UCubePrimitive cube;
cube.SetPosition(FVector3(0, 0, 0));
cube.SetColor(FColor::Red);
renderer.Draw(cube);

USpherePrimitive sphere;
sphere.SetPosition(FVector3(3, 0, 0));
sphere.SetColor(FColor::Blue);
renderer.Draw(sphere);

// Switch to 2D for UI
renderer.SetDepthTest(false);
FView uiView(FRectangle(0, 0, 1920, 1080));
renderer.SetView(uiView);

// Draw 2D sprites
USprite healthBar(healthTexture);
healthBar.SetPosition(10, 10);
renderer.Draw(healthBar);

renderer.EndFrame();
```

## OpenGL State Management

The renderer provides comprehensive OpenGL state control:

### Depth Buffer
- `SetDepthTest(bool)`: Enable/disable depth testing
- `SetDepthFunc(EDepthFunc)`: Comparison function (Less, LessEqual, etc.)
- `SetDepthMask(bool)`: Enable/disable depth writes

### Blending
- `SetBlend(bool)`: Enable/disable blending
- `SetBlendFunc(EBlendFactor, EBlendFactor)`: Source and destination factors

### Face Culling
- `SetCullFace(bool)`: Enable/disable face culling
- `SetCullFaceMode(ECullFaceMode)`: Back, Front, FrontAndBack
- `SetFrontFace(EFrontFace)`: Clockwise or CounterClockwise winding

### Lighting
- `SetLighting(bool)`: Enable/disable lighting calculations
- `SetColorMaterial(bool)`: Use vertex colors as material
- `SetShadeModel(EShadeModel)`: Flat or Smooth shading

### Texturing
- `SetTexture2D(bool)`: Enable/disable 2D texturing

### Polygon Mode
- `SetPolygonMode(ECullFaceMode, EPolygonMode)`: Fill, Line, or Point rendering

### Rendering Attributes
- `SetLineWidth(float)`: Line width in pixels
- `SetPointSize(float)`: Point size in pixels

### Matrix Stack
- `PushMatrix()` / `PopMatrix()`: Save/restore transformation matrix
- `LoadIdentity()`: Reset to identity matrix
- `Translate(x, y, z)`: Apply translation
- `Rotate(angle, x, y, z)`: Apply rotation around axis
- `Scale(x, y, z)`: Apply scaling
- `LookAt(eye, center, up)`: Camera view transformation

### Viewport
- `SetViewport(x, y, width, height)`: Set rendering viewport
- `PushScissorTest(rect)` / `PopScissorTest()`: Clipping regions

### Attributes Stack
- `PushAttributes(flags)` / `PopAttributes()`: Save/restore OpenGL state groups

## Transformation Systems

### 2D Transformations (`FTransformable2D`)

**Properties**:
```cpp
FVector2 m_origin;        // Transform origin (pivot point)
FVector2 m_position;      // Position
FRotator2D m_rotation;    // Rotation angle (degrees)
FVector2 m_scale;         // Scale factors
```

**Methods**:
- `SetPosition()` / `Move()`: Translate
- `SetRotation()` / `Rotate()`: Rotate around origin
- `SetScale()` / `Scale()`: Non-uniform scaling
- `SetOrigin()`: Set pivot point
- `GetTransform()`: Combined transformation matrix

**Usage**: Inherited by `USprite` and `UShape`

---

### 3D Transformations (`FTransformable`)

**Properties**:
```cpp
FVector3 m_origin;        // Transform origin
FVector3 m_position;      // Position
FRotator m_rotation;      // Rotation (roll, pitch, yaw in degrees)
FVector3 m_scale;         // Scale factors
```

**Methods**:
- `SetPosition()` / `Move()`: Translate in 3D space
- `SetRotation()` / `Rotate()`: Euler angle rotation
- `SetScale()` / `Scale()`: Non-uniform 3D scaling
- `SetOrigin()`: Set pivot point
- `GetTransform()`: Combined 4x4 transformation matrix
- `GetInverseTransform()`: Inverse transformation (for ray casting, etc.)

**Usage**: Inherited by `UPrimitive`

**Transform Caching**: Matrices are lazily computed and cached until properties change

## Performance Characteristics

### Rendering Performance

- **2D Rendering**: SFML-optimized vertex batching
- **3D Rendering**: Immediate mode (suitable for moderate geometry counts)
- **VR Rendering**: Dual-eye submission at HMD refresh rate (typically 90 Hz)
- **Frame Pacing**: VSync control for consistent frame times

### Threading Model

- **Render Thread**: Dedicated thread for window events and rendering
- **OpenGL Context**: Exclusive to render thread after initialization
- **Render Callback**: Invoked from render thread with thread-safe access to world

### State Changes

**Minimize expensive operations**:
- Texture switches: Use texture atlases
- Shader switches: Batch by material
- Matrix operations: Use matrix stack efficiently
- OpenGL state: Cache state to avoid redundant calls

## Design Patterns

### 1. **Abstract Factory Pattern**
`IGraphicsFactory` creates all rendering resources (`IWindow`, `IRenderer`, `ITexture`, `IShader`, `IRenderTarget`) without exposing concrete types.

### 2. **Strategy Pattern**
`IRenderer` allows swapping rendering backends (currently SFML/OpenGL, could add Vulkan, DirectX).

### 3. **Composite Pattern**
`IDrawable` enables treating individual objects and groups uniformly.

### 4. **Template Method Pattern**
`UShape::Draw()` calls abstract `GetPoint()` methods to allow derived shapes to define geometry.

### 5. **Singleton Pattern**
`FVRSystem` provides global VR system access without coupling.

### 6. **Observer Pattern**
`IWindow` uses `TEventEmitter` for window events (resized, closed, etc.).

---

## Error Handling

The renderer includes comprehensive validation:

- **Parameter Validation**: Checks for null pointers, invalid indices, zero counts
- **OpenGL Error Checking**: Optional error polling after state changes (debug builds)
- **Resource Validation**: Ensures textures and shaders are loaded before use
- **Context Validation**: Verifies OpenGL context is active on correct thread

**Thread Safety**: Rendering must occur on the render thread. The engine enforces this via the window subsystem's threading model.

---

## Usage Philosophy

The renderer architecture follows these principles:

1. **Hybrid Rendering**: Seamlessly blend 2D and 3D rendering in the same frame
2. **Multi-Threading**: Dedicated render thread prevents blocking game logic
3. **Flexibility**: Abstract interfaces enable backend swapping
4. **Performance**: Direct OpenGL access for maximum control
5. **Simplicity**: Immediate mode rendering for rapid prototyping
6. **VR Ready**: First-class VR support with OpenVR backend
7. **Resource Management**: Factory pattern for clean resource creation
8. **Event-Driven**: Window events for responsive input handling

This architecture enables complex rendering scenarios from simple 2D games to full 3D worlds with VR support, all managed by a clean subsystem that runs independently of game logic.
