# ⏱️ Runtime

## Overview

The **Runtime** module is the game framework layer of the TKD Engine, providing the essential building blocks for creating interactive games. It implements an **Actor-Component** architecture similar to Unreal Engine, offering a flexible and powerful system for game object management, world simulation, player input, animation, and game logic.

Runtime is designed to be:
- **Entity-Component Based**: Modular architecture with reusable components
- **Network-Ready**: Built-in client-side prediction and server reconciliation
- **Game-Centric**: High-level abstractions for common game patterns
- **Extensible**: Easy to derive custom actors, components, and controllers

## Architecture

The Runtime module is organized into **9 major subsystems**:

```
Runtime/
├── Actor/         - Base actor classes (AActor, APawn, ACamera, AHUD)
├── Components/    - Reusable component classes attached to actors
├── World/         - World and level management
├── Core/          - Game framework (UGame, AGameMode)
├── Controllers/   - Input controllers (Player, AI, Network)
├── Input/         - Input management system (actions, axes)
├── Time/          - Tick system and time management
├── Animations/    - Animation system (FlipBooks, state machines)
└── Physics/       - Physics enumerations and interfaces
```

## Actor Subsystem

The Actor subsystem provides the base classes for all interactive objects in the game world.

### AActor

**AActor** - Base class for all objects that can exist in the world with transform, components, and network replication support.

```cpp
class AActor : public UObject, public ITickable
{
    // Core properties
    UProperty<FTransform> m_transform;
    UProperty<Bool> m_isActive;
    TVector<Component> m_components;  // std::shared_ptr<UActorComponent>
    bool m_markedForDeletion;
    
    // Client-side prediction
    std::vector<FMoveData> m_pendingMoves;
    UInt32 m_moveTimestamp;
    
    // Server reconciliation
    UInt32 m_lastAcknowledgedMove;
    FTransform m_serverTransform;
    bool m_isTransformReplicated;
    
    // Interpolation for simulated proxies
    FTransform m_interpolationStart;
    FTransform m_interpolationTarget;
    Float32 m_interpolationAlpha;
    std::deque<FPositionSnapshot> m_positionHistory;
    Float32 m_interpolationDelay;
    
    // Network timing
    Float32 m_clientTime;
    Float32 m_estimatedRTT;
    
    // Network configuration
    static constexpr UInt32 MAX_PENDING_MOVES = 32;
    static constexpr Float32 INPUT_THRESHOLD = 0.01f;
    static constexpr Float32 MOVEMENT_UPDATE_RATE = 0.1f;
    static constexpr Float32 INTERPOLATION_TIME = 0.1f;
    
    // Events
    UFunction<AActor*> OnActorBeginOverlap;
    UFunction<AActor*> OnActorEndOverlap;
    
    // Movement RPCs
    UFunction<UInt32, Float32, Float32, FVector3, FTransform> ServerMoveRPC;
    UFunction<UInt32, Float32, FTransform> ClientAckMoveRPC;
    UFunction<FTransform, FVector3, Float32> MulticastMoveRPC;
    
    // Lifecycle
    virtual void BeginPlay();
    virtual void Tick(Float32 deltaTime);
    virtual void EndPlay();
    
    // Transform
    FTransform GetTransform() const;
    void SetTransform(const FTransform& transform);
    void Translate(const FVector3& translation);
    void Rotate(const FRotator& rotation);
    void Scale(const FVector3& factor);
    
    // Component management
    template<typename T, typename... Args>
    T* AddComponent(Args&&... args);
    
    template<typename T = UActorComponent>
    TVector<std::shared_ptr<T>> GetComponents() const;
    
    template<typename T = UActorComponent>
    T* GetComponent(const FString& name) const;
    
    template<typename T>
    void RemoveComponents();
    
    void RemoveComponent(const FString& name);
    void RemoveComponent(UActorComponent* component);
    
    // State
    Bool IsActive() const;
    void SetActive(Bool isActive);
    void MarkForDeletion();
    bool IsMarkedForDeletion() const;
    
    // Network movement
    void ApplyMovement(const FVector3& inputVector, Float32 deltaTime);
    bool IsTransformReplicated() const;
    void SetTransformReplicated(Bool replicated);
    
protected:
    // Override for custom movement simulation
    virtual FTransform SimulateMovement(
        const FVector3& inputVector,
        Float32 deltaTime,
        const FTransform& startTransform
    );
};
```

**Key Features:**

1. **Component System**: Attach multiple components for modular functionality
2. **Network Replication**: Built-in client-side prediction and server reconciliation
3. **Position Snapshots**: Smooth interpolation for simulated proxies
4. **Transform Management**: Position, rotation, scale operations
5. **Lifecycle Hooks**: BeginPlay, Tick, EndPlay for custom logic

**Usage Example:**

```cpp
// Create a custom actor
class AProjectile : public AActor
{
    DECLARE_CLASS_WITH_SUPER(AProjectile, AActor)
    
    Float32 m_speed = 1000.0f;
    FVector3 m_direction;
    
public:
    AProjectile() : AActor("Projectile")
    {
        // Add visual component
        auto* sprite = AddComponent<USpriteComponent>("Sprite");
        sprite->SetTexturePath("Assets/Projectile.png");
        
        // Add collision component
        auto* collision = AddComponent<USphereComponent>("Collision");
        collision->GetSphere().SetRadius(5.0f);
    }
    
    void SetDirection(const FVector3& dir)
    {
        m_direction = dir.Normalized();
    }
    
    void Tick(Float32 deltaTime) override
    {
        AActor::Tick(deltaTime);
        
        // Move projectile
        FVector3 movement = m_direction * m_speed * deltaTime;
        Translate(movement);
    }
};

// Spawn in world
UWorld* world = GetWorld();
AProjectile* projectile = world->SpawnActor<AProjectile>(FTransform::Identity);
projectile->SetDirection(FVector3::Forward);
```

```cpp
class APlayerCharacter : public APawn
{
    DECLARE_CLASS_WITH_SUPER(APlayerCharacter, APawn)
    
    Float32 m_moveSpeed = 300.0f;
    Float32 m_health = 100.0f;
    
public:
    APlayerCharacter() : APawn()
    {
        SetName("PlayerCharacter");
        
        // Add sprite
        auto* sprite = AddComponent<USpriteComponent>("CharacterSprite");
        sprite->SetTexturePath("Assets/Player.png");
        
        // Add collision
        auto* capsule = AddComponent<UCapsuleComponent>("Collision");
    }
    
    void Move(const FVector3& direction, Float32 deltaTime)
    {
        FVector3 movement = direction * m_moveSpeed * deltaTime;
        ApplyMovement(movement, deltaTime);  // Uses network prediction
    }
    
    void TakeDamage(Float32 amount)
    {
        m_health -= amount;
        if (m_health <= 0.0f) {
            OnDeath();
        }
    }
    
    void OnDeath()
    {
        // Death logic
        SetActive(false);
        MarkForDeletion();
    }
};
```

**Usage:**

```cpp
class AMyPlayerController : public APlayerController
{
    DECLARE_CLASS_WITH_SUPER(AMyPlayerController, APlayerController)
    
public:
    void SetupInputBindings() override
    {
        // Bind actions
        BindActionPressed("Jump", [this](EInput input) {
            if (APawn* pawn = GetPawn()) {
                // Make pawn jump
                FVector3 jumpVelocity(0, 0, 500);
                pawn->Translate(jumpVelocity * 0.016f);
            }
        });
        
        BindActionPressed("Fire", [this](EInput input) {
            FireWeapon();
        });
        
        // Bind axes
        BindAxis("MoveForward", [this](float value) {
            if (APawn* pawn = GetPawn()) {
                FVector3 movement = pawn->GetTransform().GetForward() * value;
                // Use ApplyMovement for network prediction
                pawn->ApplyMovement(movement, GetWorld()->GetDeltaTime());
            }
        });
        
        BindAxis("MoveRight", [this](float value) {
            if (APawn* pawn = GetPawn()) {
                FVector3 movement = pawn->GetTransform().GetRight() * value;
                pawn->ApplyMovement(movement, GetWorld()->GetDeltaTime());
            }
        });
    }
    
    void FireWeapon()
    {
        if (APawn* pawn = GetPawn()) {
            // Spawn projectile
            FTransform spawnTransform = pawn->GetTransform();
            AProjectile* projectile = GetWorld()->SpawnActor<AProjectile>(spawnTransform);
            projectile->SetDirection(spawnTransform.GetForward());
        }
    }
};

// Usage
AMyPlayerController* controller = world->SpawnActor<AMyPlayerController>();

controller->SetupInputBindings();
```

## Network Features

The Runtime module has extensive built-in networking support:

### Client-Side Prediction

AActor implements client-side prediction for smooth movement:

```cpp
void AActor::ApplyMovement(const FVector3& inputVector, Float32 deltaTime)
{
    if (GetNetRole() == ENetRole::AutonomousProxy) {
        // Client-controlled actor
        // 1. Simulate movement locally
        FTransform startTransform = GetTransform();
        FTransform endTransform = SimulateMovement(inputVector, deltaTime, startTransform);
        SetTransform(endTransform);
        
        // 2. Store move for reconciliation
        FMoveData moveData(m_moveTimestamp++, deltaTime, m_clientTime, 
                          inputVector, startTransform, endTransform);
        m_pendingMoves.push_back(moveData);
        
        // 3. Send to server
        ServerMoveRPC.Invoke(moveData.timestamp, moveData.deltaTime, 
                            moveData.clientTime, inputVector, endTransform);
    }
    else if (GetNetRole() == ENetRole::Authority) {
        // Server-authoritative movement
        FTransform newTransform = SimulateMovement(inputVector, deltaTime, GetTransform());
        SetTransform(newTransform);
        
        // Replicate to clients
        MulticastMoveRPC.Invoke(newTransform, inputVector, m_serverTime);
    }
}
```

### Server Reconciliation

When server acknowledges movement:

```cpp
void AActor::RPC_ClientAckMove(UInt32 timestamp, Float32 serverTime, 
                                const FTransform& serverTransform)
{
    // Remove acknowledged moves
    m_pendingMoves.erase(
        std::remove_if(m_pendingMoves.begin(), m_pendingMoves.end(),
            [timestamp](const FMoveData& move) {
                return move.timestamp <= timestamp;
            }),
        m_pendingMoves.end()
    );
    
    // Check for misprediction
    Float32 errorTolerance = 0.1f;
    if (serverTransform.GetPosition().Distance(GetTransform().GetPosition()) > errorTolerance) {
        // Reconcile: replay pending moves from server state
        SetTransform(serverTransform);
        for (const auto& move : m_pendingMoves) {
            FTransform corrected = SimulateMovement(move.inputVector, move.deltaTime, GetTransform());
            SetTransform(corrected);
        }
    }
}
```

## Design Patterns

### Actor-Component Pattern

The Runtime module uses the **Actor-Component** pattern:

- **Actors** are entities in the world
- **Components** are reusable behaviors attached to actors
- Promotes composition over inheritance
- Similar to Unity GameObjects or Unreal Actors

### Possession Pattern

Controllers **possess** pawns to control them:

```cpp
APlayerController* controller = world->SpawnActor<APlayerController>();
APlayerCharacter* pawn = world->SpawnActor<APlayerCharacter>();

controller->Possess(pawn);  // Controller now controls pawn
// Input from controller → pawn actions

controller->UnPossess();  // Release control
```

### Event-Driven Architecture

Components and actors use events for communication:

```cpp
actor->OnActorBeginOverlap.Bind([](AActor* other) {
    // Handle overlap
});

controller->On<AController::Events::Possess>([](const auto& event) {
    // Pawn was possessed
    APawn* pawn = event.pawn;
});
```

### 2. Leverage Network Prediction

```cpp
// Use ApplyMovement for networked movement
void APlayerCharacter::MoveForward(Float32 value)

    FVector3 direction = GetTransform().GetForward() * value * m_moveSpeed;
    ApplyMovement(direction, GetWorld()->GetDeltaTime());
```

### 3. Deferred Spawning During Tick

```cpp
// Avoid spawning during iteration
void Tick(Float32 deltaTime) override
{
    // DON'T: for (auto actor : world->GetActors()) { world->SpawnActor<>() }
    
    // DO: Use deferred spawning
    if (shouldSpawnEnemy) {
        world->SpawnActorDeferred<AEnemy>(spawnTransform);
    }
}

// After tick
world->ProcessDeferredSpawns();
```

```cpp
void AMyPlayerController::SetupInputBindings()
```

```cpp
void AActor::EndPlay()
```
