## Networking Architecture

The TKD Engine features a robust, production-ready networking layer designed specifically for real-time multiplayer games.

### Core Network Features

#### UDP-Based Protocol
**Location**: `Engine/Network/`

- **Asio Integration**: High-performance asynchronous I/O using the Asio library
- **Custom Binary Protocol**: Optimized packet structure for minimal bandwidth
- **IPv4/IPv6 Support**: Dual-stack networking capabilities
- **Non-Blocking I/O**: Asynchronous send/receive operations
- **Connection Management**: Client-server architecture with connection tracking

#### Packet System
**Location**: `Engine/Network/Packets/`

**Base Packet Interface** (`IPacket`):
- Type-safe packet inheritance hierarchy
- Automatic serialization/deserialization
- Virtual dispatch for packet handling

**Built-in Packet Types**:
- **Connection Packets**: `Connect`, `Disconnect`, `Ping`, `Pong`
- **State Synchronization**: `Snapshot` (full world state), `Delta` (incremental updates)
- **Remote Procedure Calls**: `RPC` for arbitrary function execution
- **Asset Transfer**: `AssetRequest`, `AssetData`
- **Authentication**: `ClientInfo`, `ServerInfo`

**Packet Structure**:
```cpp
struct FPacketHeader {
    UInt32 packetType;        // Packet type identifier
    UInt32 sequenceNumber;    // For ordering and loss detection
    UInt32 timestamp;         // Sent time for latency calculation
    UInt32 checksum;          // CRC32 integrity verification
    UInt16 payloadSize;       // Size of payload data
    UInt16 flags;            // Control flags (reliable, fragmented, etc.)
    UInt8 protocol;          // Protocol version
};
```

#### Reliability Layer
**Location**: `Engine/Network/FPacketManager.hpp`

Implements reliable transmission over UDP:

- **Acknowledgment System**: ACK/NACK packets for delivery confirmation
- **Automatic Retransmission**: Configurable timeout and retry logic
- **Selective Repeat**: Retransmit only lost packets, not entire sequence
- **Duplicate Detection**: Sequence number tracking prevents duplicate processing
- **Ordering Guarantees**: Maintains packet order for reliable channels

**Reliability Modes**:
- **Unreliable**: Fire-and-forget, lowest latency (movement updates)
- **Reliable**: Guaranteed delivery with acknowledgments (important events)
- **Ordered**: Guaranteed order, may delay delivery (chat messages)
- **Reliable-Ordered**: Both guarantees combined (critical state changes)

#### Fragmentation System
**Location**: `Engine/Network/Systems/FFragmentManager.md`

Automatic handling of large packets exceeding UDP MTU (Maximum Transmission Unit):

- **Automatic Splitting**: Divides large packets into MTU-sized fragments
- **Fragment Reassembly**: Reconstructs original packet from fragments
- **Fragment ACKs**: Per-fragment acknowledgment and retransmission
- **Out-of-Order Handling**: Accepts fragments in any order
- **Timeout Management**: Discards incomplete packets after timeout
- **Memory Efficient**: Streaming reassembly for large assets

**Configuration**:
```cpp
FFragmentManager::SetMTU(1400);              // Maximum fragment size
FFragmentManager::SetReassemblyTimeout(5.0f);  // Seconds before timeout
```

#### Checksum Validation
**Location**: `Engine/Network/FPacketManager.cpp`

CRC32-based data integrity verification:

- **CRC32 Implementation**: Fast cyclic redundancy check algorithm
- **Header Protection**: Checksums cover entire packet including header
- **Corruption Detection**: Automatically discards corrupted packets
- **Performance Optimized**: Hardware-accelerated on supported platforms

```cpp
UInt32 CalculateChecksum(const UInt8* data, SizeT size);
bool ValidateChecksum(const UInt8* data, SizeT size, UInt32 expected);
```

### Advanced Network Features

#### Snapshot System
**Location**: `Engine/Network/Packets/Snapshot.md`

Complete world state synchronization for client-server replication:

**Snapshot Contents**:
- **Snapshot ID**: Unique identifier for each snapshot
- **Timestamp**: Server time when snapshot was created
- **Actor States**: All replicated actors in the world
  - Position, rotation, scale (FTransform)
  - Velocity, angular velocity
  - Actor-specific properties
  - Component states

**Snapshot Workflow**:
1. Server captures world state at fixed intervals (e.g., 30 Hz)
2. Serializes actor data into binary snapshot packet
3. Transmits snapshot to all connected clients
4. Clients deserialize and reconcile with local state
5. Applies interpolation for smooth visual updates

**Optimization Techniques**:
- **Relevancy Filtering**: Only include actors relevant to each client
- **Delta Compression**: Send only changed properties since last snapshot
- **Prioritization**: Send critical actors first, defer less important updates
- **Bandwidth Throttling**: Adaptive rate adjustment based on network conditions

#### Interpolation System
**Location**: `Engine/Runtime/Actor/AActor.hpp`

Smooth movement between snapshots to eliminate visual stuttering:

**Interpolation Modes**:
- **Linear Interpolation**: Constant velocity between positions
- **Cubic Interpolation**: Smooth acceleration/deceleration
- **Hermite Interpolation**: Velocity-based smooth curves
- **Extrapolation**: Predict future position during packet loss

**Position Snapshot Structure**:
```cpp
struct FPositionSnapshot {
    Float32 serverTime;        // Server timestamp
    FTransform transform;      // Position, rotation, scale
    FVector3 velocity;        // Current velocity for extrapolation
    Float32 receivedTime;     // Client receive time
};
```

**Client-Side Prediction**: Reduces perceived latency by:
1. Locally predicting player movement immediately
2. Reconciling predictions with authoritative server snapshots
3. Smoothly correcting errors over time

#### Network Statistics
**Location**: `Engine/Network/FNetworkBase.hpp`

Real-time network performance monitoring:

**Tracked Metrics**:
- **Latency**: Round-trip time (RTT) in milliseconds
- **Packet Loss**: Percentage of lost packets
- **Bandwidth**: Bytes sent/received per second
- **Jitter**: Variance in packet arrival times
- **Connection Quality**: Overall connection health score

**Usage**:
```cpp
FNetworkStats stats = FNetworkBase::GetStatistics();
FLogger::Info("Latency: {}ms, Loss: {}%", stats.latency, stats.packetLoss);
```

### Actor System
**Location**: `Engine/Runtime/Actor/`

#### AActor - Base Game Object

All game entities derive from AActor:

**Actor Features**:
- **Transform**: Position, rotation, scale in 3D space
- **Lifecycle Hooks**: `BeginPlay()`, `Tick()`, `EndPlay()`
- **Component Composition**: Attach multiple components
- **Replication**: Network synchronization support
- **Visibility**: Show/hide actors dynamically

**Example Actor**:
```cpp
class AProjectile : public AActor {
private:
    FVector3 m_velocity;
    Float32 m_damage;

public:
    AProjectile() : m_velocity(FVector3::Forward * 10.0f), m_damage(25.0f) {
        // Add visual component
        auto* sprite = AddComponent<USpriteComponent>("Sprite");
        sprite->SetTexture("Textures/projectile.png");
        
        // Add collision component
        auto* collision = AddComponent<UCollisionComponent>("Collision");
        collision->SetRadius(5.0f);
    }

    virtual void BeginPlay() override {
        AActor::BeginPlay();
        // Initialization logic
    }

    virtual void Tick(Float32 deltaTime) override {
        // Update position
        FTransform transform = GetTransform();
        transform.position += m_velocity * deltaTime;
        SetTransform(transform);
        
        // Destroy after 5 seconds
        if (GetLifetime() > 5.0f) {
            MarkForDeletion();
        }
    }
};
```

```cpp
class UHealthComponent : public UActorComponent {
private:
    Float32 m_health;
    Float32 m_maxHealth;

public:
    UHealthComponent() : m_health(100.0f), m_maxHealth(100.0f) {}

    void TakeDamage(Float32 damage) {
        m_health = FMath::Max(0.0f, m_health - damage);
        if (m_health <= 0.0f) {
            GetOwner()->MarkForDeletion();
        }
    }

    Float32 GetHealth() const { return m_health; }
    Float32 GetHealthPercent() const { return m_health / m_maxHealth; }

    virtual void Tick(Float32 deltaTime) override {
        // Regenerate health over time
        if (m_health < m_maxHealth) {
            m_health += 5.0f * deltaTime;
            m_health = FMath::Min(m_health, m_maxHealth);
        }
    }
};
```

#### UPak - Asset Package

Archive format for distributing multiple assets:

**PAK File Format**:
```
Header:
  - Magic Number: 0x5041434B ("PACK")
  - Version: 1
  - Entry Count: N

Index Table (for each asset):
  - UUID Length + UUID String
  - Name Length + Name String
  - Asset Type (1 byte)
  - Data Offset (8 bytes)
  - Data Size (8 bytes)
  - Compressed Size (8 bytes)
  - Compression Flag (1 byte)

Data Section:
  - Raw asset data (concatenated)
```

**Creating PAK Files**:
```cpp
// Collect assets
std::vector<UAsset*> assets;
assets.push_back(new UAsset("Textures/player.uasset"));
assets.push_back(new UAsset("Sounds/explosion.uasset"));

// Create PAK
UPak pak;
if (pak.Create("Game.pak", assets)) {
    FLogger::Info("PAK created successfully");
}
```

**Loading from PAK**:
```cpp
// Open PAK file
UPak pak("Game.pak");
if (!pak.IsOpen()) {
    FLogger::Error("Failed to open PAK");
    return;
}

// Load specific asset
auto asset = pak.CreateAssetByName("player_sprite.png");
if (asset && asset->LoadData()) {
    // Use asset data
}

// Load asset data directly
std::vector<Byte> audioData;
if (pak.LoadAssetDataByName("explosion.wav", audioData)) {
    // Use audio data
}

// List all assets
auto entries = pak.GetAllEntries();
for (const auto& entry : entries) {
    FLogger::Info("Asset: {}, Type: {}, Size: {}",
                  entry.name, entry.type, entry.size);
}
```

```cpp
if (URessource::GetInstance().LoadPak("Assets/Game.pak")) {
    // PAK mounted successfully
```

**Benefits**:

- Seamless PAK file integration

**VR Rendering**:
```cpp
// Get eye projection matrices
FMatrix4x4 leftEyeProj = FVRSystem::GetEyeProjectionMatrix(EVREye::Left);
FMatrix4x4 rightEyeProj = FVRSystem::GetEyeProjectionMatrix(EVREye::Right);

// Get eye-to-head transforms
FMatrix4x4 leftEyeTransform = FVRSystem::GetEyeToHeadTransform(EVREye::Left);
FMatrix4x4 rightEyeTransform = FVRSystem::GetEyeToHeadTransform(EVREye::Right);

// Render for each eye
for (EVREye eye : {EVREye::Left, EVREye::Right}) {
    FRenderTexture* eyeTexture = GetEyeRenderTexture(eye);
    renderer->SetRenderTarget(eyeTexture);
    
    FMatrix4x4 viewMatrix = GetHMDPose() * GetEyeTransform(eye);
    FMatrix4x4 projMatrix = GetEyeProjection(eye);
    
    RenderScene(viewMatrix, projMatrix);
    
    // Submit to VR compositor
    FVRSystem::Submit(eye, eyeTexture->GetTextureID());
}
```

## Animation System

#### UFlipBook - Sprite Animation

Frame-based 2D animation system:

**Creating Animations**:
```cpp
UFlipBook walkAnimation;
walkAnimation.AddFrame("Textures/walk_01.png", 0.1f);  // 100ms per frame
walkAnimation.AddFrame("Textures/walk_02.png", 0.1f);
walkAnimation.AddFrame("Textures/walk_03.png", 0.1f);
walkAnimation.AddFrame("Textures/walk_04.png", 0.1f);
walkAnimation.SetLooping(true);
```

**Playing Animations**:
```cpp
// On sprite component
auto* sprite = actor->GetComponent<USpriteComponent>();
sprite->PlayAnimation(&walkAnimation);

// Control playback
sprite->PauseAnimation();
sprite->ResumeAnimation();
sprite->StopAnimation();
sprite->SetAnimationSpeed(1.5f);  // 1.5x speed
```

**Animation Events**:
```cpp
walkAnimation.OnAnimationComplete.Connect([]() {
    FLogger::Info("Walk animation completed");
});

walkAnimation.OnFrameChanged.Connect([](int frameIndex) {
    if (frameIndex == 2) {
        // Play footstep sound on frame 2
        FAudioInterface::PlaySound("footstep.wav");
    }
});
```

**Sprite Sheet Support**:
```cpp
UFlipBook spriteSheetAnim;
spriteSheetAnim.LoadFromSpriteSheet(
    "Textures/character_spritesheet.png",
```
